# 前端品牌与登录

- 品牌符号与字标：`frontend/src/brand/Brand.tsx`、`frontend/src/brand/brand.css`。符号路径、字标排版与品牌色复用自见衡科技官网。
- 浏览器图标：`frontend/public/favicon.svg`，与官网一致。
- 登录页与会话加载页见 [LoginPage.tsx](../frontend/src/login/LoginPage.tsx)，页面缩放与版式见 [login.css](../frontend/src/login/login.css)。
- 登录页书法标语见 [以技术](../frontend/src/login/slogan-technology.png) 和 [见未来](../frontend/src/login/slogan-future.png)。
- 发件人、主题、正文编辑与实时预览见 [MailSettingsPage.tsx](../frontend/src/settings/MailSettingsPage.tsx)，正文图片缩放见 [MailImage.ts](../frontend/src/settings/MailImage.ts)，共用正文样式见 [mail-message-body.css](../frontend/src/settings/mail-message-body.css)，内置头图见 [brand-header.png](../backend/src/main/resources/mail/brand-header.png)。
- 邮件编辑与预览的布局见 [mail-settings.css](../frontend/src/settings/mail-settings.css)，保存交互测试见 [MailSettingsPage.test.tsx](../frontend/src/settings/MailSettingsPage.test.tsx)。
- 登录与重置密码的表单交互见 [LoginPage.tsx](../frontend/src/login/LoginPage.tsx)，验证入口见 [LoginPage.test.tsx](../frontend/src/login/LoginPage.test.tsx)。
- 登录态与右上角账号菜单（我的档案、退出登录）入口：`frontend/src/App.tsx`，菜单样式见 [styles.css](../frontend/src/styles.css) 的 `.account-menu`。
- 接口错误约定：后端错误响应统一带 `message` 文案，兜底处理见 [ApiErrors.java](../backend/src/main/java/com/jianheng/emp/web/ApiErrors.java)；前端在 [api.ts](../frontend/src/api.ts) 对缺失 `message` 的响应按状态码生成可读说明，不在提示里只显示状态码。
- 附件预览：PDF 通过同源 iframe 加载 `/api/attachments/{id}/preview`（[AttachmentPreview.tsx](../frontend/src/documents/AttachmentPreview.tsx)）；服务端 `X-Frame-Options` 必须为 `SAMEORIGIN`，配置见 [SecurityConfiguration.java](../backend/src/main/java/com/jianheng/emp/security/SecurityConfiguration.java)。
- 侧边栏导航与 `Section` 类型：[navigation.tsx](../frontend/src/navigation.tsx)；分组展开与选中样式见 [styles.css](../frontend/src/styles.css) 的 `.sidebar` 段。窄屏抽屉导航的断点见 [useMediaQuery.ts](../frontend/src/useMediaQuery.ts)。
- 我的消息：唯一全量入口 `/messages` 见 [MessagesPage.tsx](../frontend/src/notifications/MessagesPage.tsx)；工作台只显示未读前三条（[DocumentWorkspace.tsx](../frontend/src/documents/DocumentWorkspace.tsx)），顶栏铃铛只预览最近五条（[NotificationBell.tsx](../frontend/src/notifications/NotificationBell.tsx)）。消息行与标读行为见 [NoticeItem.tsx](../frontend/src/notifications/NoticeItem.tsx) 和 [useNoticeOpener.ts](../frontend/src/notifications/useNoticeOpener.ts)，单据详情统一通过 [useDocumentViewer.tsx](../frontend/src/documents/useDocumentViewer.tsx) 打开。
- 页面路由：`Section` 与 URL 的映射见 [navigation.tsx](../frontend/src/navigation.tsx) 的 `sectionPaths`/`sectionFromPath`，入口 `BrowserRouter` 见 [main.tsx](../frontend/src/main.tsx)；无效或无权限 URL 回退首页。
- 全屏 mis 水印：[EmployeeWatermark.tsx](../frontend/src/watermark/EmployeeWatermark.tsx)，样式见 [watermark.css](../frontend/src/watermark/watermark.css)。水印为固定全屏层，覆盖页面和弹窗，不拦截交互。
- 水印身份取 `/api/session/me` 的 `mis`，未绑定员工的账号回退登录账号 `username`；字段来源见 [AccountService.java](../backend/src/main/java/com/jianheng/emp/security/AccountService.java)。
- 应用外壳顶栏在页面滚动时吸顶，样式见 [styles.css](../frontend/src/styles.css) 的 `.topbar`。
- 全局色板：`frontend/src/styles.css` 的 `:root` 设计令牌，Ant Design 主题对齐该色板（浅色选中底 `colorPrimaryBg`、`colorPrimaryBgHover` 显式指定，避免深色主色自动派生出的偏灰色阶）；主题与 dayjs 中文区域：`frontend/src/main.tsx`。
- 日期与时间输入统一使用 [dates.tsx](../frontend/src/dates.tsx)：对外是 `YYYY-MM-DD` / `YYYY-MM-DDTHH:mm` 字符串，内部封装 Ant Design `DatePicker`；跨字段的下限用 `notBefore`，无效日期用 `disabledDate`。
- 图表统一使用 [EChart.tsx](../frontend/src/charts/EChart.tsx) 入口；人员管理的部门占比、人员流动和司龄结构见 [PeopleCharts.tsx](../frontend/src/people/PeopleCharts.tsx)，其中人员流动数据来自 [PeopleController.java](../backend/src/main/java/com/jianheng/emp/people/PeopleController.java) 的 `/people/employment-flow`。
- 列表头像统一使用 [EmployeeCard.tsx](../frontend/src/people/EmployeeCard.tsx) 的 `EmployeeCardAvatar`，点击按需读取 [PeopleController.java](../backend/src/main/java/com/jianheng/emp/people/PeopleController.java) 的 `/people/directory/{id}` 员工名片。
- 弹窗统一使用 Ant Design `Modal` 的 `centered`，包括申请编辑弹窗；长表单在 modal body 内滚动，实现见 [DraftEditor.tsx](../frontend/src/documents/DraftEditor.tsx) 和 [styles.css](../frontend/src/styles.css) 的 `.draft-editor-modal` 段。
- 列表分页统一复用 [common.tsx](../frontend/src/common.tsx) 的 `listPagination`（总数 + 10/20/50 条每页），新增列表直接传入；工作台「最近申请」、单据明细和部门树等嵌入式或层级列表不分页。
- 邮件设置见 [MailSettingsPage.tsx](../frontend/src/settings/MailSettingsPage.tsx)；正文图片与品牌头都存放在 `EMP_UPLOAD_DIR/mail`，服务端见 [MailImageStore.java](../backend/src/main/java/com/jianheng/emp/security/MailImageStore.java)，接口返回 `cid:` 供 Resend 作为内嵌附件发送。
- 未保存修改的离开守卫见 [leaveGuard.tsx](../frontend/src/leaveGuard.tsx)：`useLeaveGuard` 统一拦截站内链接、F5、Vite 开发期整页重载与页面卸载，`LeaveConfirmModal` 提供「不保存 / 取消 / 保存并离开」；邮件设置与员工档案共用，接入点见 [MailSettingsPage.tsx](../frontend/src/settings/MailSettingsPage.tsx) 和 [EmployeeProfile.tsx](../frontend/src/people/EmployeeProfile.tsx)。
- 实时刷新：登录后保持一条 `/api/events` 的 SSE（后端见 [LiveEventsController.java](../backend/src/main/java/com/jianheng/emp/web/LiveEventsController.java)、[SseRegistry.java](../backend/src/main/java/com/jianheng/emp/web/SseRegistry.java)、[WorkflowNotifier.java](../backend/src/main/java/com/jianheng/emp/approval/WorkflowNotifier.java)），业务事务提交后才推「有更新」信号；前端收到即重拉当前视图，连接不可用时降级为前台 30 秒轮询，回到前台或恢复联网立即补刷，实现见 [useLiveEvents.ts](../frontend/src/useLiveEvents.ts)，列表刷新键见 [useResource.ts](../frontend/src/useResource.ts)。未读计数取服务端 `/api/notifications/unread`，同时供顶栏铃铛、侧边栏「我的消息」角标和消息页使用；待办角标取 `/api/inbox/count`，在登录、SSE、进入「我的待办」以及审批动作完成后刷新（动作完成由 [DocumentDetail.tsx](../frontend/src/documents/DocumentDetail.tsx) 派发 `workflow-changed` 事件），见 [App.tsx](../frontend/src/App.tsx)。
- 流程呈现统一使用 [process.tsx](../frontend/src/process.tsx)：`ProcessFeed` 是头像节点时间线，节点状态、状态标签、时间、审批人与意见由数据驱动；节点头像复用 [avatar.tsx](../frontend/src/people/avatar.tsx)，数据字段来自 `Summary`/`TaskView`/`Event`/`Payment`/`AuditMapper.Entry` 的 `avatarKey`，其中未激活的待审批节点取 `TaskView` 的审批人；人事变动按最新在上展示并标出最新/起点，申请详情的「审批记录」由 [ApprovalProcess.tsx](../frontend/src/documents/ApprovalProcess.tsx) 组装发起、审批和付款节点。
